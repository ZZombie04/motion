# 모션 — 타이밍·이징·카메라의 문법

좋은 모션은 눈에 띄지 않는다. 보는 사람은 "부드럽다"고만 느낀다. 그 부드러움은 아래 숫자에서 나온다.

## 1. 이징

| 이름 | 곡선 | 쓰는 곳 | 길이 |
|---|---|---|---|
| `mo.out` | 빠르게 출발, 길게 감속 | **모든 등장**(글자·카드·선) | 0.7–1.1s |
| `mo.soft` | 부드러운 감속 | 작은 것, 느린 것, 흐림 해제 | 0.5–1.0s |
| `mo.inOut` | 천천히–빠르게–천천히 | A에서 B로 **이동·변신**, 와이프, 막대 | 0.6–1.0s |
| `mo.cam` | 느긋한 출발, 아주 긴 착지 | **카메라** | 1.2–2.4s |
| `mo.in` | 가속하며 떠남 | **퇴장** | 0.3–0.55s |
| `mo.snap` | 즉시 붙음 | 박자 타격, 슬램 | 0.3–0.45s |
| `mo.swift` | 날카로운 가감속 | 휩, 빠른 이동 | 0.4–0.6s |
| `mo.spring` | 8% 넘쳤다 돌아옴 | 버튼·체크·작은 카드 | 0.45–0.6s |
| `mo.pop` | 16% 넘쳤다 돌아옴 | 칩·점·배지만 | 0.5–0.6s |
| `mo.settle` | 2% 넘쳤다 앉음 | 큰 패널의 변신·착지 | 0.8–1.0s |
| `none` | 등속 | 마키·회전·타이핑 진행·느린 드리프트 | — |

숫자 카운트는 0에서 출발하면 `power3.out`, **이미 화면에 서 있던 값에서 출발하면 `power3.inOut`·`mo.cam`**(멈춰 있다가 갑자기 최고 속도로 튀지 않게), 커서는 `mo.inOut`.

**퇴장은 등장의 절반.** 들어올 때 0.9초면 나갈 때 0.4초. 나가는 것은 주목받을 필요가 없다.

## 2. 스태거와 겹침

- 같은 무리의 요소는 **0.05–0.1초 간격**으로(줄 0.1, 어절 0.055, 글자 0.024, 목록 0.09, 카드 0.07).
- 무리가 6개를 넘으면 간격을 줄여 전체가 0.6초 안에 끝나게 한다.
- **앞 동작이 60–70% 진행됐을 때 다음을 시작**한다. 하나가 끝나고 다음이 시작되면 뚝뚝 끊긴다.
- 순서는 읽는 순서: 라벨(0.0) → 제목(+0.1) → 강조(+0.9) → 보조(+0.4) → 버튼(+0.2).
- 한 화면의 등장은 대체로 1.5초 안에 끝내고, 그 뒤는 읽는 시간.

## 3. 시간 배분

| 대상 | 화면에 머무는 최소 시간 |
|---|---|
| 한 단어(박자 컷) | 0.4s |
| 짧은 제목(≤10자) | 0.8–1.0s(등장 후 정지) |
| 두 줄 제목 | 1.2–1.6s |
| 한 문장 설명 | 글자 수 × 0.06s + 0.4s |
| 결과 숫자 | 착지 후 1.0–1.5s |
| UI 끝 상태 | 0.8s 이상 |
| 엔드카드 | 2.0s 이상(마지막 1초는 새 요소 없이) |

훅은 **0초에 이미 진행 중**이어야 한다: `M.reveal('#num', { type: 'chars', pre: 0.4 }, 0)` — 첫 프레임에 이미 40% 들어와 있다. 직접 트윈할 때는 시작값을 "30–40% 들어온 상태"로 준다(`yPercent: 64` 등).

## 4. 12원칙 가운데 실제로 쓰는 것

| 원칙 | 여기서의 구현 |
|---|---|
| 감속·가속(Easing) | §1 표 |
| 예비 동작(Anticipation) | 큰 이동 직전 반대로 2–4% 물러남: `tl.to(el, { x: -u, duration: 0.12 })` 후 본 이동. 버튼 누름(`M.press`)도 예비 동작 |
| 따라오기·겹침(Follow-through/Overlap) | 부모가 멈춘 뒤 자식이 0.05–0.1초 늦게 멈춤. 스태거 자체가 겹침 |
| 호(Arc) | 커서는 직선으로 가지 않는다(`cur.moveTo`가 자동으로 휜다). 날아드는 카드는 `x`와 `y`의 이징을 다르게 |
| 보조 동작(Secondary) | 주 동작에 그림자·빛·배지가 반응: 완료 순간 `mo-sheen`, 착지에 `M.pulse`, 클릭에 지평선 밝아짐 |
| 스쿼시·스트레치 | 거의 쓰지 않는다(캐주얼한 인상). 쓴다면 점·공 같은 작은 도형에만 5–10% |
| 타이밍의 대비 | 느린 장면 뒤에 빠른 전환, 빠른 전환 뒤에 홀드. 같은 속도가 3초 이상 이어지지 않게 |
| 과장 | 줌 스루 15배, 숫자 화면 폭 80% — 할 때는 확실히 |

## 5. 카메라 어휘와 코드

```js
// 정착: 비스듬히 있던 화면이 바로 선다(훅에 겹친다)
cam.set({ rx: 9, ry: -12, zoom: 1.16 });
cam.to({ rx: 0, ry: 0, zoom: 1, duration: 2.3, ease: 'mo.out' }, 0);

// 푸시 인: 중요한 것에 다가간다
cam.lookAt('#card', { zoom: 1.2, duration: 1.8 }, 3.0);

// 오빗: 대상을 사이에 두고 천천히 돈다(들어갈 때 한 번, 그 뒤로 길게)
cam.to({ ry: -8, rx: 3.5, zoom: 1.04, duration: 1.25 }, 6.0);
cam.to({ ry: 6, rx: 1, zoom: 1.09, duration: 2.5, ease: 'mo.inOut' }, 6.9);

// 풀백 리빌: 꽉 찬 화면에서 물러나면 더 큰 맥락
cam.set({ zoom: 2.8, x: cardCx, y: cardCy });
cam.to({ zoom: 1, x: M.W / 2, y: M.H / 2, ry: -10, duration: 2.0 }, 0.7);

// 트럭 + 패럴랙스: 레이어마다 다른 속도로 흐른다
// <div class="mo-layer" data-z="-600">…</div> <div class="mo-layer" data-z="0">…</div> <div class="mo-layer" data-z="240">…</div>
cam.to({ x: M.W / 2 + M.u * 14, duration: M.D, ease: 'sine.inOut' }, 0);

// 랙 포커스: 앞 카드에서 뒤 화면으로 초점 이동
cam.set({ aperture: 2.6, focus: 240 });
cam.to({ focus: -600, duration: 0.9, ease: 'mo.inOut' }, 2.2);

// 아이소 → 정면: 구조를 내려다보다 바로 선다
cam.set({ rx: 52, rz: -28, zoom: 0.82 });
cam.to({ rx: 0, rz: 0, zoom: 1, duration: 1.8 }, 2.4);

// 오토 줌: 커서가 갈 곳을 먼저 보여 준다(커서보다 0.1초 늦게)
cur.moveTo('#toggle', 2.0);  cam.lookAt('#toggle', { zoom: 1.5, duration: 1.0 }, 2.1);

// 줌 스루: 요소의 한 점을 뚫고 지나간다(글자 0의 안쪽 등)
const z = M.rect('#zero'), h = M.rect('#hook');
tl.to('#hook', { scale: 15, transformOrigin: `${z.cx - h.x}px ${z.cy - h.y}px`, duration: 0.85, ease: 'power3.in' }, 2.5);
tl.to('#hook', { autoAlpha: 0, duration: 0.14 }, 3.2);
tl.from('#next', { scale: 0.62, autoAlpha: 0, duration: 1.0, ease: 'mo.out' }, 2.95);   // 다음 장면은 멀리서 다가온다

// 충격
cam.shake({ amp: M.u * 0.8, duration: 0.3 }, 4.0);
```

- 카메라 트윈은 **같은 속성을 동시에 두 번** 걸지 않는다. 오빗 중에 줌을 바꾸려면 한 트윈에 함께 넣거나 시간이 겹치지 않게 한다.
- 각도의 감: 3–6° 은은한 입체, 8–14° 분명한 3D, 20°+ 과감(짧게만). 세로 화면에서는 `ry`를 10° 이내로.
- `zoom`으로 확대할 때 대상이 화면 밖으로 나가지 않는지 시트로 확인한다(폭 900px 요소는 1.18배가 한계). 여백 예산: 좌우 여백 m%인 요소는 `zoom = 50 / (50 − m)`에서 화면 끝에 닿는다(8% → 1.19배).
- 기울인 채 확대해도 렌더는 선명하다(그 프레임만 2–3배로 찍는다, 3.3배까지). 미리보기에서만 흐려 보인다.
- 모션 블러는 렌더러가 **실제 셔터처럼** 만든다. 빠른 이동일수록 자연히 번진다 — 가짜 잔상·블러 필터를 넣지 않는다.

## 6. 박자에 맞추기

```js
const b = M.beats(128);            // 한 박 0.469초
['READY', '달리고', '던지고', '넘고'].forEach((w, i) => {
  M.transition('cut', i ? `#w${i - 1}` : null, `#w${i}`, { at: b(i) });
  tl.fromTo(`#w${i} h1`, { scale: 1.18 }, { scale: 1, duration: b.len * 0.8, ease: 'mo.snap' }, b(i));
});
```

- 컷은 박의 **정각**에(`M.beats`가 프레임 격자에 맞춰 준다), 타격 애니메이션은 0.3–0.4초 안에 끝낸다. 컷 안은 계속 미세하게 움직인다(`cam.drift`).
- 타격은 `M.reveal(el, { type: 'slam' }, b(i))` 한 줄로도 된다. 컷마다 `cam.punch({ scale: 1.04 }, b(i))`를 얹으면 화면 전체가 박을 받는다.
- 박자 영상의 검수는 `motion sheet --beats 128`(박마다 한 장).
- 4박·8박 단위로 구조를 바꾼다(배경 반전, 레이아웃 변화). 마지막 2–4박은 홀드.
- 음악 파일이 없어도 BPM을 정해 두면 나중에 음악을 얹기 쉽다(`--audio`).

## 7. 미세 상호작용 사전

| 순간 | 구현 |
|---|---|
| 버튼 누름 | `M.press(btn, t)` + `cur.click(t)` |
| 입력 시작 | 플레이스홀더 `autoAlpha 0`(0.2s) → `M.type` |
| 입력하면 버튼 활성 | `tl.to(btn, { backgroundColor: '#3D7BFF', color: '#fff', duration: 0.25 }, t)` |
| 로딩 → 완료 | `M.spin(spinner)`; `tl.to(spinner, { scale: .4, autoAlpha: 0, duration: .18 }, t)`; `M.fill(check, { ease: 'mo.spring', duration: .5 }, t + .06)` |
| 항목 활성화 | 글자 `opacity .45 → 1`, 오른쪽 메타 `from { autoAlpha: 0, x: u }` |
| 진행 | `M.fill(bar, { from: i/3, to: (i+1)/3, ease: 'mo.inOut', duration: .55 }, t)` — 단계마다 끊어서 |
| 숫자 착지 | `M.count(n, { …, pulse: { target: num, scale: 1.06 } }, t)` — 최종 숫자가 뜨는 프레임에 맞춰 준다(직접 맞출 땐 반환값의 `.land`) |
| 선택 | 나머지 `opacity .35`, 선택한 것 `scale 1.04` + `mo-ring` |
| 토글 | `M.fill(toggle, { duration: .35, ease: 'mo.spring' }, t)` |
| 알림 도착 | `M.reveal(noti, { type: 'drop' }, t)` |
| 완료의 빛 | `tl.fromTo(card, { '--sheen': -0.3 }, { '--sheen': 1.3, duration: .9, ease: 'mo.inOut' }, t)`(카드에 `mo-sheen`) |

## 8. 끊기지 않게 잇는 요령

1. 장면 A의 퇴장과 장면 B의 등장을 **0.2–0.4초 겹친다**.
2. 카메라는 장면 경계에서 멈추지 않고 다음 자세로 계속 움직인다.
3. 살아남는 요소 하나를 정해 `top/left/width/height/borderRadius` 또는 `M.morph`로 다음 자리까지 옮긴다.
4. 전체에 `cam.drift`와 `cam.float`가 깔려 있으면 정지 구간도 숨 쉰다.
5. 배경의 빛을 영상 전체에 걸쳐 아주 느리게 한 번 움직인다(지평선이 15초 동안 4% 떠오름).
