# 자막과 내레이션 — 말에 맞춰 단어가 켜진다

쇼츠는 대부분 소리 없이 시작해서 본다. 내레이션이 있는 영상이라면 자막은 선택이 아니라 화면의 일부다.

## 1. 흐름

| 상황 | 하는 일 |
|---|---|
| 대본만 있고 녹음은 아직 | `motion captions plan 대본.txt --rate 5 --out script.srt` → 화면을 그 시간에 맞춰 짠다. 나중에 녹음이 오면 align으로 바꾼다 |
| 대본 + 녹음 | `motion captions align 대본.txt voice.wav --out voice.captions.json` → 단어 시각까지 맞은 자막 |
| 자막 파일(SRT/VTT)이 이미 있다 | 그대로 `M.captions('#cap', 'given.srt')` — 단어 시각은 음절 비율로 나뉜다 |
| 녹음만 있고 대본이 없다 | 대본을 받아 적어 달라고 사용자에게 한 번 묻거나, 사용자가 받아 적은 글을 받는다(음성 인식은 내장하지 않는다) |

`align`은 녹음의 쉬는 구간을 찾아 문장을 맞춘 다음, 문장 안의 단어를 말하는 시간에만 음절 비율로 나눈다. 한국어는 음절마다 길이가 비슷해 단어 강조가 자연스럽게 맞는다.
문장 안에서 잠깐 쉬면 그 자리에 가장 가까운 단어 경계가 쉼에 붙는다(쉼 동안 다음 단어가 미리 켜지지 않는다). 음절은 읽는 대로 센다: `AI` = 에이아이 4, `GPT` = 지피티 3, `120` = 백이십 3, `2026` = 이천이십육 5, `62%` = 육십이 퍼센트 6, `Claude` = 클로드 3.

## 2. 대본 쓰는 법(화면용)

- 한 문장은 한 생각. 쉼표로 이어 붙인 긴 문장은 둘로.
- 숫자는 말하는 대로 쓰되(“십 분”), 화면의 큰 숫자는 따로 디자인한다(`10분`).
- 말 속도: 차분한 설명 초당 4.5음절, 보통 5, 빠른 쇼츠 6. 영상 길이 = 대본 음절 수 ÷ 속도 + 앞뒤 1초.
- 자막 한 줄은 쇼츠 16–22자, 가로 영상 28–36자(`--max`로 조절). 줄을 넘는 문장은 자동으로 의미 단위에서 나뉜다.

## 3. 스타일 고르기

| 스타일 | 언제 |
|---|---|
| `karaoke` | 기본. 설명·강의·인터뷰. 지금 단어만 포인트 색 |
| `pop` | 쇼츠·릴스, 에너지 있는 말투. 단어가 말하는 순간 튀어나온다 |
| `box` | 강조가 강한 홍보 쇼츠. 지금 단어 뒤에 포인트 색 상자 |
| `line` | 차분한 다큐·공공 안내. 단어 강조 없이 줄만 |

## 4. 자리와 크기

- 기본 자리는 `.mo-captions`: 아래 안전영역 바로 위, 가운데 정렬. 쇼츠는 화면 높이의 62–75% 근처가 손가락·버튼과 겹치지 않는다.
- 크기 `--cap: 5.6`(u). 쇼츠 5.2–6.4, 가로 4.2–5.2.
- 자막이 있는 영상은 화면의 다른 글자를 줄인다. 자막과 제목이 한 화면에 겹쳐 읽히면 안 된다(제목은 위 1/3, 자막은 아래).
- 밝은 배경 위 자막은 그림자 대신 반투명 띠를 깔거나 테마를 어둡게.

## 5. 화면과 말을 맞추기

```js
M.captions('#cap', 'voice.captions.json', { style: 'karaoke' });
// 말과 그림을 맞추고 싶은 순간은 자막 파일의 시각을 읽어 쓴다
M.reveal('#chart', { type: 'fade' }, 4.34);          // "이제 인공지능에게…"가 시작되는 시각
M.count('#n', { from: 120, to: 10 }, 12.73);           // "준비 시간은…"
```

- 그림은 말보다 0.2–0.4초 **먼저** 바뀐다.
- 말하는 동안 화면이 멈춰 있지 않게, 문장마다 작은 움직임 하나(강조어 형광펜, 숫자, 아이콘).
- 핵심 단어는 자막 말고 화면 본문에 크게 한 번 더 보여 준다(자막은 따라 읽고, 본문은 기억한다).
