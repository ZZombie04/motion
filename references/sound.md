# 소리 — 화면이 절반이면 소리가 나머지 절반

같은 영상도 소리가 붙으면 완성도가 한 단계 올라 보인다. 반대로 아무 데나 붙인 효과음은 영상을 싸 보이게 만든다.
원칙은 하나: **소리는 움직임의 결과다.** 화면에서 무언가가 닿고, 열리고, 바뀌는 순간에만 소리가 난다.

## 1. 세 겹

| 층 | 무엇 | 크기(기본값) | 넣는 법 |
|---|---|---|---|
| 음악 | 영상 전체의 박자와 감정 | 0.8 · 끝 1.5초 페이드 | `<audio src="bgm.mp3" data-start="0" data-fade-out="1.5">` |
| 목소리 | 내레이션·인터뷰 | 1.0 · 음악은 자동으로 줄어든다 | `<audio src="voice.wav" data-role="voice" data-start="0.4">` |
| 효과음 | 움직임의 마침표 | 소리마다 정해진 레벨 × volume | `M.sfx('whoosh', t)` · 도우미에 `sfx: true` |

렌더러가 셋을 섞고, 목소리가 나오는 동안 음악을 낮추고(덕킹), 전체를 −14 LUFS(유튜브·쇼츠 기준)로 맞추고, 최대값을 −1 dB 아래로 묶는다. 음량을 손으로 맞출 일은 거의 없다.
효과음만 있는 영상은 드문드문한 소리라 −14까지 끌어올리면 타격감이 뭉개진다. 그래서 한 번의 증폭으로 키우고, 가장 큰 타격만 빠른 리미터로 최대 8 dB까지 누른다(보통 −15 ~ −19 LUFS). 더 크게 들려야 하면 음악을 깐다.

## 2. 효과음 사전 — 무엇에 무엇을

| 화면의 순간 | 소리 | 메모 |
|---|---|---|
| 큰 글자가 박자에 맞춰 쾅 | `impact` | 영상 전체에 2–3번까지. 매번 쓰면 무뎌진다 |
| 장면이 옆으로 넘어감(push·slide·whip) | `whoosh` · `whip` | 움직임이 시작하는 프레임에(도우미가 맞춰 준다) |
| 작은 칩·배지·점이 튀어나옴 | `pop` | 여러 개가 연달아 나오면 첫 개와 마지막 개만 |
| 버튼 클릭·커서 클릭 | `click` | 화면 속 UI가 눌리는 바로 그 프레임 |
| 휴대폰 탭 | `tap` | |
| 타이핑 | `key` (`M.type(..., { sfx: true })`) | 자동으로 키마다 음높이가 조금씩 다르다 |
| 숫자가 오름 | `tick` (`M.count(..., { sfx: true })`) | 자동으로 최대 30번, 착지에는 `ding`을 따로 |
| 완료·성공 | `success` · `ding` | 체크가 그려지는 순간, 한 번만 |
| 오류·거절 | `error` | |
| 형광펜·밑줄·선 긋기 | `swipe` | |
| 부드러운 등장(카드·문단) | `swish` | 대부분은 소리 없이 두는 편이 낫다 |
| 다음 장면을 기대하게(긴장) | `riser` → 직후 `impact` | riser 끝(1.7초 뒤)이 impact 시각에 오게 `at - 1.7`에 |
| 빛샘·공개 | `swell` | 반전·공개 직전 1초 |
| 카드·기기가 바닥에 닿음 | `thud` | |
| 저음 강조(로고 착지) | `drop` | 영상에 한 번 |
| 사진·캡처 | `shutter` | |
| 디지털 오류·전환 | `glitch` | glitch 전환과 함께 |
| 반짝임(축하·완성) | `sparkle` | 색종이·빛살과 함께 |

## 3. 밀도와 간격

- 효과음은 **영상 10초에 4–8개**가 보통이다. 박자 영상(키네틱 타이포)은 박마다 넣어도 되지만 음악이 있으면 효과음은 강박에만.
- 0.5초 안에 효과음이 4개 넘게 겹치면 `check`가 알려 준다(자판·틱은 예외).
- 소리 없이 지나가는 등장이 있어야 소리가 들린다. 모든 등장에 `sfx: true`를 붙이지 않는다.
- 같은 소리가 반복되면 `pitch`를 0.9–1.1로 조금씩 바꾼다: `M.sfx('pop', { pitch: 1.06 }, t)`.
- 효과음은 화면보다 **늦으면 안 된다.** 도우미가 계산한 시각을 쓰고, 직접 넣을 때도 움직임이 시작하는(닿는) 프레임에.

## 4. 음악과 화면을 맞추기

```html
<audio src="bgm.mp3" data-start="0"></audio>
```
```js
const music = M.audio('bgm.mp3'), b = M.grid();          // CLI가 분석한 실제 박
M.reveal('#w1', { type: 'slam' }, b(0));                 // 박 위에 컷과 타격
M.reveal('#w2', { type: 'slam' }, b(1));
M.transition('flash', '#s1', '#s2', { at: music.downbeats[2] });   // 마디의 첫 박에 큰 변화
M.onFrame((t) => { glow.style.opacity = (0.25 + 0.75 * music.low(t)).toFixed(3); });   // 저음에 맞춰 숨 쉬는 빛
```

- **컷과 큰 변화는 마디의 첫 박(downbeats)**, 작은 등장은 박, 아주 작은 디테일은 반박(`b(4.5)`).
- 음악의 세기(`level`·`low`)는 배경의 빛·입자·막대처럼 **장식에만** 연결한다. 글자 크기를 음악에 연결하면 읽기 힘들다.
- 박자 시트로 확인한다: `motion sheet 파일 --beats music`(박마다 한 장).
- 음악 파일이 없으면 `data-bpm="120"`을 무대에 두고 같은 방식으로 짠다. 나중에 같은 BPM의 음악을 넣으면 그대로 맞는다.
- 사용자가 음악 생성 도구를 연결해 두었다면 영상 길이·BPM·분위기를 정해 만들고, 받은 파일을 `<audio>`로 넣는다(가사 없는 연주곡).

## 5. 목소리

- 녹음이 있으면 자막과 함께 쓴다: `motion captions align 대본.txt voice.wav` → `M.captions` (`references/captions.md`).
- 목소리가 시작하기 0.3–0.5초 전에 화면이 먼저 움직인다(사람은 먼저 보고 듣는다).
- 목소리 구간에는 효과음을 줄인다(`volume: 0.5`).

## 6. 하지 않는 것

- 저작권을 모르는 음악·효과음 파일을 내려받아 넣지 않는다. 사용자가 준 파일이나 내장 효과음만.
- 첫 프레임부터 큰 소리로 시작하지 않는다(음악은 `data-fade-in="0.2"`).
- 끝을 뚝 자르지 않는다(음악 `data-fade-out`은 1–1.5초, 기본 0.8).
- 무음으로 써야 하는 곳(발표 화면, 소리 없이 재생되는 피드)에 효과음을 깔지 않는다. 그런 요청이면 `--no-audio`.
